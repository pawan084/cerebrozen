> Audited 2026-08-04 on the Windows host — **static read only, no xcodebuild** (per
> docs/IOS_PARITY.md posture). Every finding below was verified against the actual Swift
> source at the cited line. Parity items are measured against the Android 2026-08
> eight-wave page polish (Home rotating eyebrow / cached-first snapshot / optimistic
> check-in bubble / say-more bridge; Sleep evening framing / editable diary / duration

> numbers / widget opened-state; Journal WRITE pill / word count / journal-new deep

## Server-plan / sync drift

23. [BUG] The real server "agentic plan" is invisible where plans live: Home's "Today's plan" row and `DailyPlanView` always render the static `Dummy.planSteps` — even signed-in with a live `RemotePlan` — while the real plan (with `toggleStep` wiring) renders only inside the Account screen (`CloudSyncView`). Two parallel plans; the fake one is the visible one (apps/ios/CereBro/Features/Home/HomeView.swift:38-43, 377-394; Features/Cloud/CloudSyncView.swift:56-77)
24. [BUG] Sync is one-way (up only): `journalHistory()` is defined and never called, and moods/sleep are mirrored up but never fetched — a returning user on a fresh device sees NONE of their server journal/moods/sleep (they see the fake Dummy entries instead, finding 3) (apps/ios/CereBro/Networking/APIClient.swift:465; Networking/BackendService.swift:547-570)
25. [RISK] `refresh_token` is received, stored nowhere, and never used — there is no `/auth/refresh` call although the backend ships one, so every access-token expiry hard-fails to "Your session expired. Please sign in again." (apps/ios/CereBro/Networking/APIClient.swift:5, 268-288; backend/app/api/routes/auth.py:272)
26. [RISK] Bearer token persists in plaintext `UserDefaults` (`cerebro_access_token`), not the Keychain — for a privacy-first mental-health product the session credential is unencrypted at rest and rides device backups (apps/ios/CereBro/Networking/APIClient.swift:301-339)
27. [RISK] iOS registers push via the legacy single-token `PUT /users/me/push-token` while the backend has the newer multi-device `/users/me/devices` (POST/DELETE + PushStatusOut) — two-device users clobber each other's token (apps/ios/CereBro/Networking/APIClient.swift:681-684; backend/app/api/routes/users.py:479 vs 516-545)
28. [BUG] Mood intensity is a lie of the UI: the check-in eyebrow promises "Mood, intensity and trigger", no intensity/trigger control exists, and `mirrorMood` hardcodes `intensity: 3` for every sync — the server's intensity data is fabricated (apps/ios/CereBro/Features/Home/HomeView.swift:326; Networking/BackendService.swift:551)
29. [BUG] A companion-style change made while signed out is lost across relaunch — `pendingCompanion` is memory-only and `MainTabView.task` re-seeds region/consent/attest/assessment at launch but never the companion, so the next-launch sign-in syncs everything except the chosen style (apps/ios/CereBro/Networking/BackendService.swift:59, 175-179; Navigation/RootView.swift:90-110)
30. [RISK] iOS never reconciles the streak against `GET /users/me/streak` although the endpoint exists and ARCHITECTURE names the computation a cross-stack contract — local drift (timezone, reinstall wiping `activeDays`) is undetectable (apps/ios/CereBro/CereBroApp.swift:353-374; backend/app/api/routes/users.py:68)
31. [BUG] Trusted contact can't be removed on iOS — backend ships `DELETE /users/me/trusted-contact`; the client offers save-only, `method` is hardcoded "email", and there is zero client-side validation of the email (apps/ios/CereBro/Features/Safety/SafetyViews.swift:128-198; backend/app/api/routes/users.py:168)
